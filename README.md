# CoworkingGitPractice

Учебный проект для практической работы №4.

## Назначение

Проект демонстрирует применение системы контроля версий Git к конкретному C#/.NET проекту.

## Структура

- `src/` — исходный код;
- `tests/` — тесты;
- `docs/` — документация;
- `resources/` — дополнительные ресурсы;
- `.gitignore` — исключения Git.

## Запуск

```powershell
dotnet run --project src/CoworkingGitPractice/CoworkingGitPractice.csproj
```
